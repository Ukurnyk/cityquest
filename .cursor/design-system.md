# Questly Design System

## 🎨 Цветовая палитра

### Основные цвета

- Primary: `#4B6CFF` - насыщенный синий
- Accent: `#FF6B4A` - оранжево-красный
- Secondary: `#A06EFF` - лавандово-фиолетовый

### Дополнительные цвета

- Background: `#F7F8FA` - светло-серый фон
- Card: `#FFFFFF` - белый для карточек
- Text: `#2B2D42` - тёмно-серый для текста
- Muted: `#7B7F9E` - серо-синий для второстепенного текста

## 🔤 Шрифты

### Основной шрифт

- Inter / SF Pro Display / Poppins

### Размеры

- H1: 28-32pt, bold
- H2: 22-24pt, semi-bold
- Body: 16pt, regular
- Small: 12-14pt, muted

## 🧱 Компоненты UI

### Кнопки

- Primary:

  - background: `#4B6CFF`
  - text: `#FFFFFF`
  - border-radius: 12px
  - padding: 16px

- Secondary:

  - border: 1px solid `#4B6CFF`
  - text: `#4B6CFF`
  - background: transparent

- FAB:
  - круглая форма
  - иконка +
  - background: `#FF6B4A`

### Карточки

- background: `#FFFFFF`
- shadow: 1-2
- border-radius: 16px

### Иконки

- Стиль: линейные (Lucide/Heroicons)
- Цвет: в тон текста
- Активные: `#FF6B4A`

### Навигация

- Bottom tab bar: 4-5 иконок
- Active Tab: `#FF6B4A`
- Inactive Tab: серо-синий

## 🌗 Темы

### Светлая

- Background: `#F7F8FA`
- Card: `#FFFFFF`
- Text: `#2B2D42`

### Тёмная

- Background: `#1C1C2E`
- Card: `#2C2C3E`
- Text: `#F0F0FA`

## ✨ Анимации

- Ачивки: всплытие + вибрация
- Навигация: слайд
- Прогресс-бары: градиент (синий → фиолетовый)
